# Together We Can (TWC) Rehabilitation Centre Website

Official modern website for **Together We Can (TWC) Rehabilitation**, a drug and alcohol rehabilitation centre situated in Eendekuil, Western Cape, South Africa.

Built with **React**, **Vite**, **Tailwind CSS**, and **TypeScript**. Fully optimized for deployment on **Vercel** and **GitHub Pages**.

---

## 🌟 Features

- **Modern Glassmorphism UI**: Beautiful, calm, responsive design crafted with Tailwind CSS and Radix UI primitives.
- **Full Navigation & Routes**:
  - **Home**: Hero section, core pillars, daily routine overview, testimonials, and mission.
  - **About Us**: Story, values, philosophy, and team introduction.
  - **Information & Programs**: 12-step celebrate recovery, MRT, daily activities, rules, and admission guidelines.
  - **Gallery**: Responsive image showcase highlighting the farm and facilities.
  - **Contact**: Location map, telephone lines, email addresses, and contact inquiry form.
- **Fast Performance**: Bundled with Vite for instant loading and high lighthouse scores.
- **Vercel Zero-Config Ready**: Configured with `vercel.json` SPA routing rewrites.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` or `pnpm` or `yarn`

### Installation

```bash
# Clone the repository
git clone https://github.com/nicomonlineza-alt/TWCnick1.git

# Navigate to project directory
cd TWCnick1

# Install dependencies
npm install
```

### Development

```bash
# Start local development server
npm run dev
```

Open `http://localhost:3000` in your browser.

### Build & Production

```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```

---

## ☁️ Deploying to Vercel

1. Push this repository to GitHub (`nicomonlineza-alt/TWCnick1`).
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import the `TWCnick1` repository.
4. Framework preset will automatically be detected as **Vite**.
5. Click **Deploy**.
